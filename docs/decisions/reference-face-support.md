# 기준 면 곡면 지원 범위

## Decisions

- 기준 크기 이상인 평면, 원통면, 원뿔면은 기준 면으로 사용할 수 있다.
- 기준 크기 이상인 구면, 토러스면, B-spline을 포함한 자유곡면이 하나라도 있으면 해석용 CAD를 만들지 않고 해당 면을 사용자에게 표시한다.

## Boundaries

- 원뿔면 지원은 형상 종류를 기준 면 후보로 받아들인다는 뜻이며, 품질 기준을 완화하지 않는다. 결과는 여전히 단일 유효 폐곡면 solid이고 원본 대비 부피 IoU가 90% 이상이어야 한다.
- 기준 크기보다 작은 원뿔면은 다른 작은 요소와 같은 규칙을 적용한다. 사용자가 남길 부분으로 표시하지 않으면 기준 면에 포함하지 않는다.
- 구면, 토러스면, 자유곡면의 지원 방법은 이 결정에서 정하지 않는다.

## Why

실제 기능 시험 부품은 기본 기준 크기 2mm에서 큰 면 725개 중 평면 700개, 원통면 13개, 원뿔면 12개로 구성된다. 평면과 원통면만 허용하면 주 시험 부품이 재구성을 시작하지도 못한다. 반면 확인되지 않은 모든 곡면을 한꺼번에 허용하면 닫힌 solid 구성과 품질 판정의 실패 원인을 넓히므로, 실제 부품에 필요한 원뿔면까지만 지원 범위를 확장한다.

## Reconsider when

- 원뿔면을 포함한 실제 부품에서 단일 유효 폐곡면 solid와 부피 IoU 90%를 반복해서 만들 수 없을 때
- 구면, 토러스면 또는 자유곡면 때문에 실제 대상 부품이 반복해서 차단되고, 그 곡면을 기준 면으로 구성하는 검증 방법이 마련됐을 때

## Still-rejected alternatives

- 평면과 원통면만 지원 — 기본 2mm에서 실제 시험 부품의 큰 원뿔면 12개가 전체 작업을 차단한다.
- 모든 곡면을 곧바로 지원 — 곡면 종류별 연장·교차 방식과 결과 품질이 검증되지 않아 실패 원인을 통제하기 어렵다.

## Evidence worth preserving

- `CFD_M-X0070ABSB_front_panel.stp`는 솔리드 1개, 크기 580.8×510.6×20.0mm, 면 2,966개다. 기본 2mm에서 큰 면은 평면 700개, 원통면 13개, 원뿔면 12개다.
- 큰 원뿔면 12개는 전면 좌표상 여섯 위치에 두 면씩 모여 있다. 네 위치는 약 `(-263.4,-26.0)`, `(-132.3,-26.0)`, `(-263.4,30.9)`, `(-132.3,30.9)`이고, 두 위치는 약 `(-223.1,201.4)`, `(223.1,201.4)`이다.
